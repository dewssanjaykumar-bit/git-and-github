Git and GitHub

What is Git?

Git is a distributed version control system that allows developers to track changes in their codebase, collaborate with others, and manage different versions of their projects.

What is GitHub?

GitHub is a web-based platform that uses Git for version control and provides a collaborative environment for developers to host and review code, manage projects, and build software together.

Key Features of Git

  • Distributed architecture
  • Branching and merging
  • Staging area for commits
  • Support for multiple workflows

Key Features of GitHub

  • Code hosting and collaboration
  • Pull requests for code review
  • Issue tracking and project management
  • Integration with CI/CD tools

Getting Started with Git and GitHub

  1. Install Git on your local machine.
  2. Create a GitHub account.
  3. Create a new repository on GitHub.
  4. Clone the repository to your local machine.
  5. Make changes to your code and commit them using Git.
  6. Push your changes to the remote repository on GitHub.

Basic Git Commands

A quick reference guide for essential version control commands.

1. Setup & Configuration

Command Description
git config --global user.name "Name" Set your global username for commits.
git config --global user.email "email" Set your global email for commits.
git init Initialize a new local Git repository.

2. Basic Workflow

Command Description
git status Check the status of your working directory and staging area.
git add <file> Add a specific file to the staging area.
git add . Add all modified and new files to the staging area.
git commit -m "Message" Commit staged changes with a descriptive message.

3. Working with Remote Repositories

Command Description
git clone <url> Clone a remote repository to your local machine.
git remote add origin <url> Connect your local repository to a remote server.
git push -u origin main Push local commits to the remote repository (main branch).
git pull Fetch and merge changes from the remote repository.

4. Branching & Merging

Command Description
git branch List all local branches.
git checkout -b <name> Create and switch to a new branch.
git checkout <name> Switch to an existing branch.
git merge <name> Merge the specified branch into your current branch.
